# Nguồn của fixture (chatbot P1)

Mọi file trong thư mục này **tự viết theo trang tài liệu công khai của nhà cung cấp**, đọc ngày **27/11/2026** bằng công cụ đọc trang.
**Không** chép từ lời gọi thật (P1 không gọi Groq hay Gemini; đo thật là việc của chatbot X1). Dữ liệu là dữ liệu mẫu tổng hợp.
Fixture KHÔNG chứa khoá API. Trong test, khoá giả dựng bằng `fakeSecretValue()` (xem `common/testing/sample-secrets.ts`).

Chuỗi `THAN-LOI-KHONG-DUOC-RO` nằm trong mọi thân lỗi mẫu: nếu nó xuất hiện trong thông điệp lỗi hay log thì thân lỗi đã rò (HDA-15).

| File                              | Hình dạng                                                                                                                                                                                                                                                                                                  | Nguồn                                                                                                                                                           |
| --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `groq/request.json`               | thân `POST https://api.groq.com/openai/v1/chat/completions`: `messages`, `response_format.json_schema{name, strict: true, schema}`, `reasoning_effort`, `include_reasoning`, `max_completion_tokens`                                                                                                       | https://console.groq.com/docs/structured-outputs ; https://console.groq.com/docs/reasoning                                                                      |
| `groq/response-ok.json`           | chữ của mô hình ở `choices[0].message.content` (chuỗi JSON). Trang **không** có mẫu phản hồi HTTP thô, nên chỉ có các khoá trang nêu (không `id`, không `usage`)                                                                                                                                           | như trên                                                                                                                                                        |
| `groq/error-*.json`               | `{ "error": { "message", "type" } }`. Giá trị `type` ngoài `invalid_request_error` là chỗ giữ chỗ (trang chỉ nêu hình dạng)                                                                                                                                                                                | https://console.groq.com/docs/errors                                                                                                                            |
| `gemini/request.json`             | thân `POST https://generativelanguage.googleapis.com/v1beta/interactions`: `system_instruction` (chuỗi), `input` (mảng bước `user_input` / `model_output`, không có `role`), `store: false`, `response_format{type: "text", mime_type: "application/json", schema}`, `generation_config.max_output_tokens` | https://aistudio.google.com/docs/structured-output ; https://aistudio.google.com/api-reference/interactions-api ; https://aistudio.google.com/docs/interactions |
| `gemini/response-ok.json`         | bước `thought` đứng trước bước `model_output`; chữ ở `steps[].content[].text`; `status: "completed"`                                                                                                                                                                                                       | tham chiếu Interactions API (tài nguyên Interaction)                                                                                                            |
| `gemini/response-incomplete.json` | `status: "incomplete"` («completed, but contains incomplete results (e.g. hitting max_tokens)»)                                                                                                                                                                                                            | như trên                                                                                                                                                        |
| `gemini/error-*.json`             | `{ "error": { "code", "message" } }`, `code` dạng snake_case (`rate_limit_exceeded`, `invalid_request`, `api_error`), không có `status`                                                                                                                                                                    | https://aistudio.google.com/docs/api-errors                                                                                                                     |
| `weird-body.txt`                  | thân HTML của cổng trung gian, không phải JSON (dùng cho 200 lẫn 502)                                                                                                                                                                                                                                      | tình huống "thân lạ" của HDA-15                                                                                                                                 |

Header của yêu cầu (kiểm trong test, không nằm trong fixture): Groq `Authorization: Bearer <khoá>`; Gemini `x-goog-api-key: <khoá>` và `Api-Revision: 2026-05-20` (ví dụ REST của trang có header này, trang không nói bắt buộc; duyệt D1).

Chưa xác nhận được bằng trang (chatbot X1 M1 đo thật): Groq dùng chung `reasoning_effort` và `include_reasoning` với `json_schema` ở `gpt-oss-20b`; tên trường `usage` của Groq.
