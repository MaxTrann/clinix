# Tracking — module `auth`

Nhật ký tiến độ riêng của module `auth`. Kế hoạch, task, phụ thuộc và danh sách test case nằm ở
[`PLAN.md`](PLAN.md); file này chỉ ghi việc **đã làm** để sau này giải thích lại được (luồng chạy, test nào pass,
chỗ nào phát sinh vấn đề). Giữ vĩnh viễn trong repo, không xoá sau khi merge.

**Cách ghi**
- Thêm một dòng mới **sau mỗi task** (mã task `P*`/`A*`/`F*`/`D*`/`X*` theo PLAN.md), mới nhất ở cuối.
- "Test case": liệt kê mã test case ở mục 7 của PLAN.md (ví dụ `DK-01, DK-02`); "Kết quả": `Pass` / `Fail` / `Một phần` (ghi rõ
  ca nào ở cột cuối). Ca `Fail` phải có dòng sau ghi cách xử lý và lần chạy lại.
- Đổi kế hoạch khi đang làm thì sửa `PLAN.md`; ghi lý do ở cột cuối của dòng tương ứng.
- Khi cả module xong: thêm **đúng một dòng** vào `docs/TRACKING.md` ở gốc, trỏ sang file này.

8. **(A4, 27/10/2026) Guard đã sẵn sàng cho admin C1 và mọi controller `/admin/*`.** `JwtAuthGuard` và `RolesGuard` là guard **toàn cục** (đăng ký bằng `APP_GUARD` trong `AuthModule`, mà admin đã import để dùng `SessionService`), nên controller **không gắn guard nào**: mặc định cần đăng nhập, chỉ cần khai báo vai trò và lấy người dùng. Ví dụ (đường dẫn import tính từ `src/admin/branches/`):

   ```ts
   import { Controller, Get } from '@nestjs/common';
   import { CurrentUser, type AuthenticatedUser } from '../../auth/decorators/current-user.decorator.js';
   import { Roles } from '../../auth/decorators/roles.decorator.js';

   @Roles('QuanTriVien') // ở class hoặc method; sai vai trò ⇒ 403, không token ⇒ 401
   @Controller('admin/branches')
   export class BranchesController {
     @Get()
     list(@CurrentUser() user: AuthenticatedUser) { // user = { accountId, sessionId, role }
       // …
     }
   }
   ```

   Mã lỗi: 401 `CHUA_DANG_NHAP` / `TOKEN_KHONG_HOP_LE` / `PHIEN_HET_HIEU_LUC`, 403 `KHONG_DU_QUYEN` (mã 403 dùng chung với plan admin 5.9). Endpoint công khai (kích hoạt nhân sự B16) gắn `@Public()` ở method hoặc class. `@RequireAdminScope`/`AdminScopeGuard` của admin gắn bằng `@UseGuards` nên luôn chạy **sau** hai guard toàn cục và đọc được `request.user`. Test của admin dựng bằng `AuthModule` chạy guard thật: controller thử trong test phải `@Public()` hoặc gửi token thật (mẫu: `apps/api/test/auth-guards.e2e-spec.ts`).
